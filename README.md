# 공유누리 UX/UI 콘셉트 데모

`index.html`을 열면 로컬에서 바로 시연할 수 있습니다. 웹 서버에서 확인하려면 이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 여세요.

1. 메인의 검색창에 **배드민턴**을 입력해 검색합니다.
2. 첫 시설을 열고 11월 26일 또는 27일을 선택한 뒤 **선택**을 누릅니다.
3. 시간대를 선택하고 **이 일정으로 신청**을 누릅니다.
4. 예시 신청자명, `010-0000-0000`, 이용 인원과 목적을 입력하고 필수 동의 두 개를 체크합니다.
5. **신청 내용 확인 → 예약 신청 제출 → 예약 내역 확인** 순서로 진행합니다.

예약 데이터는 브라우저 메모리에만 유지되며 페이지를 새로고침하면 초기화됩니다. 예시 시설, 날짜와 시간대는 시연용 가상 데이터입니다. 이 웹 구현은 Figma 인스턴스와 별도로 작성한 HTML·CSS·JavaScript입니다.

배포 승인 후 정적 호스팅에 `index.html`, `styles.css`, `app.js`, `assets/`를 함께 올리면 됩니다. 빌드, 서버 로직, 환경변수, 외부 예약 API가 필요하지 않습니다. 공개 호스팅에 올리기 전 프로젝트에 포함된 이미지와 로고의 공개 사용 권한을 확인하세요.
